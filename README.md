# 🚀 Space Mission 2D Game

## Project Description
Space Mission 2D Game is an interactive browser-based game where players control a spaceship, collect science crystals, and avoid asteroids. The game helps players understand space missions through an engaging gaming experience.

## Objectives
- Develop a 2D space game.
- Improve player coordination and decision-making.
- Create an interactive space mission simulation.
- Make learning about space fun.

## Technologies Used
- HTML – Structure of the game
- CSS – Game design and styling
- JavaScript – Game logic and controls
- GitHub – Code hosting
- GitHub Pages – Website deployment

## Game Features
- 2D spaceship movement
- Space background
- Moving asteroids
- Crystal collection
- Fuel management
- Score system
- Mission success and failure conditions

## How to Play
1. Open the game website.
2. Click Start / Restart Mission.
3. Use arrow keys or W, A, S, D to move the spaceship.
4. Collect 5 blue crystals.
5. Avoid asteroids.
6. Manage fuel to complete the mission.

## Game Controls
- Up Arrow / W – Move up
- Down Arrow / S – Move down
- Left Arrow / A – Move left
- Right Arrow / D – Move right
